# SVAR Identification Atlas

An interactive guide to structural vector autoregression identification methods, with visual explanations, method comparisons, and reproducible MATLAB examples.

## Live site

Visit the Atlas at <https://saschakew.github.io/SVAR-Identification-Atlas/>.

## Local preview

Serve the repository root with any static file server. For example:

```text
python -m http.server 8000
```

Then open <http://localhost:8000/apps/atlas/>.

## Deployment

Pushes to `main` deploy `apps/atlas` to GitHub Pages.
